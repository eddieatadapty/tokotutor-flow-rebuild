Day 1

Pass the Meta campaign into Adapty

After a one-time SDK setup, the campaign each install came from arrives as a user attribute and picks the flow at first open. No app release.

Week 1

One flow per promise

“Too old?”, “time or money” and “7 days” each get their own first screens; your founder-story ads open the “time or money” flow.

Week 2

Judge each ad on what it earns

Each flow against today’s, measured on trials, paid subscriptions and what each install from that ad earns, so spend follows the promise that pays.

All three phones run the whole flow with the five ideas. Your ads run on Meta only; we found no Apple Ads for Toko, so search is untested. This layer carries no range: only a test per ad can give one.
